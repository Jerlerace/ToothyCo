# Toothy Clinic App - Version 1.0 Release Notes

This document lists the modules, pages, and functionalities that are currently implemented and working in **Version 1.0** of the Toothy Clinic App.

---

## 🔑 Authentication & Session Management (TC001)
- **Splash Screen (`lib/auth/splash/`)**:
  - Automatically checks if a user session exists in Supabase.
  - Dynamically routes signed-in users to the unified dashboard or redirects unauthenticated users to the Sign In screen.
- **Sign In Page (`lib/auth/p_sign_in/`)**:
  - Handles secure logins via Supabase Auth.
  - Validates email formatting.
- **Sign Up Page (`lib/auth/p_sign_up/`)**:
  - Handles new user registration.
  - Enforces email validation and password requirements.
  - New registrants are added to the cloud database in real-time.
- **Session Persistence**:
  - The login session is securely persisted on the device, allowing users to bypass log in on subsequent launches.

---

## 👥 Unified Dashboard & Role Redirection (TC001 / TC002)
- **Unified Homepage (`lib/homepage_unified/`)**:
  - A single landing interface that resolves the user's role from the cloud database profile.
  - **Dynamic Dashboards**:
    - **Patient Dashboard**: Tailored views for browsing clinic costs, schedules, and booking.
    - **Dentist Dashboard**: Displays dentist-specific actions and schedule controls.
    - **Admin Dashboard**: Access to admin-specific tools (User management, Procedure management).

---

## 🛠️ Admin User Management & Role Assignment (TC002)
- **User Management Portal (`lib/admin/user_management/p_user_management/`)**:
  - Admins can view a cloud-synced list of all registered users (queried directly from Supabase).
  - Admins can select any user to view their current role details.
  - Admins can modify a user's role (Patient, Dentist, Admin) and save the change, syncing immediately to the database.
- **Dentist Details & Coding (`lib/admin/admin_dentist_info/`)**:
  - Dynamic visual color-coding to distinguish dentist types/specialties in the listing interface.

---

## 💰 Procedure & Cost Transparency (TC005)
- **Procedure Management Portal (`lib/admin/procedures/`)**:
  - **View Procedures (`p_procedures_view_admin`)**: Displays all dental services and categories with estimated pricing from the cloud.
  - **Add Procedure (`c_admin_add_procedure`)**: Admins can add new dental services (specifying name, category, and cost).
  - **Edit Procedure (`p_procedures_edit_admin`)**: Admins can modify existing procedure descriptions and pricing in real-time.
  - **Delete Procedure (`c_admin_del_procedure`)**: Admins can remove retired services.
- **Read-Only Cost View**:
  - Patients can view the estimated prices in a read-only format for budgeting purposes, while admins/dentists hold write permissions.

---

## 🗓️ Dentist Scheduling (TC004 - ONGOING)
- **Dentist Schedule Management (`lib/admin/p_admin_schedule_dentist/`)**:
  - Foundation code and pages for setting/viewing dentist schedules and block-out requests.
