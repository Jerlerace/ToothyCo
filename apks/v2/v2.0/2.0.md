# Toothy Clinic App - Version 2.0 Release Notes

This document lists the new and updated modules, pages, and functionalities that are fully active and tested in **Version 2.0** of the Toothy Clinic App.

---

## 🔑 System-Wide Authentication & Routing (TC001 / TC002)
- **Automatic Role Redirection**: Logs users in and routes them to their role-specific dashboard (Patient, Dentist, or Admin).
- **Header Customization**: Greetings header dynamically personalizes using the database profile data (e.g., `"Hello, Dr. John Doe 👋"`).
- **Profile Custom Badges**: Dynamically colors and displays role tags (e.g., custom green label for **Dentist**) in the Profile section.

---

## 📋 Role 1: Patient Features (TC001 / TC003 / TC005 / TC006 / TC008 / TC009)
- **New Account Registration (TC001)**:
  - Forms validate password matching and email formatting.
  - Automatically initializes new user rows in the database upon sign up.
- **Medical Profile & Records Management (TC003)**:
  - Patients can view and update emergency contacts, blood type, allergies, and conditions.
  - Data syncs instantly to Supabase and locks back to read-only mode after saving.
- **Procedure Cost Transparency (TC005)**:
  - Displays categorised clinic rates in a strictly read-only catalog view.
- **Appointment Booking (TC006)**:
  - Prevents double-bookings by checking slot availability in real-time.
  - Fires in-app notification alerts upon successful booking.
- **AI-Driven Slot Suggestions (TC008)**:
  - Analyzes clinic traffic for the selected date and suggests the 3 quietest time slots based on patient traffic trends.
- **In-App FAQ Chatbot (TC009)**:
  - Floating action button opens a chat assistant.
  - Resolves questions about pricing lists and clinic staff; outputs helper contact details for out-of-scope requests.

---

## 📋 Role 2: Dentist Features (TC004 / TC007 / TC010)
- **Schedule Availability Management (TC004)**:
  - Doctors can toggle active weekdays and pick clinic start/end timings.
- **Leave & Vacation Requests Filing (TC004)**:
  - Select date range and submit leave requests.
  - Monitor previous files and cancel pending requests (deletes from database).
- **Treatment Records Linkage (TC007)**:
  - Dropdown options to log patient procedures, enter clinical remarks, and link them to database records.
- **Fulfillment & Clinic Analytics (TC010)**:
  - View analytics charts including monthly income trends, treatment frequency graphs, and fulfillment gauges.
- **Patient Historical Treatment Tracker**:
  - Browse chronological logs (newest first) of patient procedures, notes, and attending dentists.

---

## 📋 Role 3: Admin Features (TC002 / TC004)
- **Dentist Leave Approval Panel**:
  - Review pending leave files; approving updates the status badge to approved and notifications alert the doctor.
- **Dentist Registration Approval**:
  - Review credentials of new medical registrations and approve/activate accounts.
- **Procedure Cost Management (TC005)**:
  - Add, edit, and delete procedure names, categories, and prices.
- **User Role Modification (TC002)**:
  - Manage all system users, adjust roles (Patient, Dentist, Admin), and set dentist specializations.
