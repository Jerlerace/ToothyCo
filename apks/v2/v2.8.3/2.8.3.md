# Toothy Clinic App - Version 2.8.3 Release Notes

This release adds timeout protections to background database initialization tasks to prevent infinite freezes or hangs on the splash screen on slow devices and emulators (such as Bluestacks).

## Key Changes
1. **Database Initialization Timeout Protection**:
   * Added an `8-second timeout` guard to `SupaFlow.initialize()` inside `main()` in [main.dart](file:///C:/BiboyStuffs/Flutterflow/toothy_c_o/lib/main.dart).
   * If local storage locks or network hangs block Supabase initialization for longer than 8 seconds, it will raise a timeout exception.
   * This exception is caught by the app's initialization try-catch boundary and rendered on screen in a diagnostic details pane, preventing the app from hanging indefinitely on the splash screen.

2. **Preloaded Splash UI**:
   * Renders the purple splash screen instantly on launch to prevent native boot loading delays.

3. **Staging Build**:
   * Compiled and staged the APK as `version 2.8.3.apk` inside `apks\v2.8.3\`.
