# Toothy Clinic App - Version 2.8 Release Notes

This release resolves the early boot white screen crash and loading latency by replacing the blank router loader with the styled purple splash screen immediately on launch and reducing the splash transition delay.

## Key Changes
1. **Removed Startup White Loading Screen**:
   * Modified the GoRouter page builder in [nav.dart](file:///C:/BiboyStuffs/Flutterflow/toothy_c_o/lib/flutter_flow/nav/nav.dart) to return `SplashWidget()` as the loading placeholder instead of a centered circular progress indicator on a blank white page.
   * On startup, the app immediately draws the purple splash screen while resolving authentication status, eliminating the white screen transition.

2. **Accelerated Transitions**:
   * Reduced the splash screen delay in [main.dart](file:///C:/BiboyStuffs/Flutterflow/toothy_c_o/lib/main.dart) from `1000` to `600` milliseconds, allowing a faster transition to the home page or login screen once Supabase resolves the session.

3. **Self-Contained Error Widget Boundary**:
   * Wrapped the custom `ErrorWidget.builder` in a `Directionality` (using `ui.TextDirection.ltr`) and `Material` canvas to guarantee that early bootstrap crashes successfully render their stack traces on screen.

4. **Asynchronous Stream Exception Guards**:
   * Subscribed to both the `userStream` and `jwtTokenStream` in `main.dart` using explicit `onError` handlers to catch and report session parsing errors.

5. **Lottie Network Fallback Guards**:
   * Added `errorBuilder` parameters to all `Lottie.network` widgets in the codebase ([splash_widget.dart](file:///C:/BiboyStuffs/Flutterflow/toothy_c_o/lib/auth/splash/splash_widget.dart) and [p_dashboard_dentist_widget.dart](file:///C:/BiboyStuffs/Flutterflow/toothy_c_o/lib/dentist/p_dashboard_dentist/p_dashboard_dentist_widget.dart)) to show fallback icons rather than crash when offline.

6. **Staging Build**:
   * Re-compiled and overwrote the APK at `apks\v2.8\version 2.8.apk`.
