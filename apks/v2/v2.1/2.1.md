# Toothy Clinic App - Version 2.1 Release Notes

This release addresses compilation, syntax, and package deprecation errors that arose from updates to the project widgets, backend configurations, and dependencies.

---

## 🔧 Bug Fixes & Code Improvements in v2.1

1. **Supabase Initialization Fix (`lib/backend/supabase/supabase.dart`)**:
   - Removed the deprecated `detectDeepLink` parameter from `FlutterAuthClientOptions`. The `supabase_flutter` client SDK (v2.9.0) now handles native deep links and authentication callbacks automatically without explicit client-side options parameters.
   
2. **Patient UUID Creation Correction (`lib/admin/user_management/patient_management/p_patient_management/p_patient_management_widget.dart`)**:
   - Replaced the undefined `SystemUUID().uuid()` call with the correct, preconfigured local `generateUUID()` method inside the patient creation logic.

3. **Dentist Appt. Widget Fix (`lib/dentist/appointment_related/p_appointments/p_appointments_widget.dart`)**:
   - Added the missing `FlutterFlowIconButton` import at the top of the file to resolve compilation failures on the back navigation buttons.

4. **Model Import Cleanup (`lib/admin/procedures/p_procedures_edit_admin/p_procedures_edit_admin_model.dart`)**:
   - Removed the unused, broken import statement referencing the old deleted `c_admin_del_procedure_widget.dart` component.
